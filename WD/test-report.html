3. Web Application Security Audit

Rigorous defense-in-depth principles implemented across the entire StudentHub codebase.

✔
SQL Injection Protection: All database operations in db.php, register.php, students.php, manage-events.php, and api-students.php strictly utilize Parameterized Prepared Statements (bind_param and PDO prepare).
✔
Cross-Site Scripting (XSS) Mitigation: All user-supplied data rendered into HTML views is sanitized using htmlspecialchars($var, ENT_QUOTES, 'UTF-8') and safe template interpolation.
✔
Cross-Site Request Forgery (CSRF) Tokens: All administrative POST mutations (event creation, student deletion, user status toggles) require synchronized 64-character cryptographic tokens validated via hash_equals().
✔
Cryptographic Password Hashing: Passwords are never stored in plaintext or fast hashes (MD5/SHA1). Passwords use BCRYPT via password_hash($pass, PASSWORD_BCRYPT) with salt auto-generation and password_verify().
✔
Session Fixation & Inactivity Timeout: Session IDs are regenerated immediately upon successful login via session_regenerate_id(true). Sessions automatically expire after 15 minutes of inactivity.
✔
Upload Directory Execution Protection: The uploads/events/ and private/ folders contain dedicated .htaccess directives disabling execution of any PHP, CGI, or executable scripts.

4. Apache Virtual Host Local Deployment Guide (Intermediate Extension)

Follow these steps to deploy StudentHub under a custom local domain: http://studenthub.local.

Step 1: Edit Windows Hosts File (C:\Windows\System32\drivers\etc\hosts)

Open Notepad as Administrator and append this mapping:

127.0.0.1 studenthub.local 127.0.0.1 www.studenthub.local

Step 2: Add VirtualHost in XAMPP (C:\xampp\apache\conf\extra\httpd-vhosts.conf)

<VirtualHost *:80> ServerAdmin admin@charusat.ac.in DocumentRoot "C:/Codding Pratice/WD" ServerName studenthub.local ServerAlias www.studenthub.local <Directory "C:/Codding Pratice/WD"> Options Indexes FollowSymLinks MultiViews AllowOverride All Require all granted </Directory> ErrorLog "logs/studenthub-error.log" CustomLog "logs/studenthub-access.log" common </VirtualHost>

Step 3: Restart Apache & Verify

Restart Apache from the XAMPP Control Panel and navigate to http://studenthub.local in your browser!
