You must use your official university student ID (e.g., D26DCE173) and the registered password you created during enrollment. If you are a new student, complete the Student Registration form first.

As demonstrated in Practical 5, JavaScript regular expressions check input format (10-digit mobile, complex password, valid university email) on input and blur events, providing instant visual feedback and preventing erroneous HTTP requests.

In Practical 6, JavaScript uses the modern fetch() API to retrieve data/events.json, data/students.json, and data/faqs.json. The received data is parsed and filtered with debounced search, category selectors, ascending/descending sorting, and client-side pagination of 6 items per page.

In Practical 7, forms submit via HTTP POST. PHP verifies an anti-CSRF token using hash_equals(), sanitizes inputs, enforces length and character restrictions, protects CSV writes with exclusive file locking (flock), and safely renders stored records back to the browser with htmlspecialchars().
